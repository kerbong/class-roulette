# 우리 반 룰렛

교실에서 쓰려고 만든 구슬 룰렛 추첨기입니다.
구슬 물리 엔진은 [lazygyu/roulette](https://github.com/lazygyu/roulette)(MIT)를 그대로 쓰고,
그 위에 **학급 운영에 필요한 것들**을 얹었습니다.

## 원본과 뭐가 다른가

| | 원본 | 우리 반 룰렛 |
|---|---|---|
| 명단 입력 | 매번 이름 붙여넣기 | **번호(1번~N번) 기본**, 저장해두고 여러 반 전환 |
| 설정 | 맵·속도·등수를 손으로 | 상황 7가지 중 하나만 클릭 |
| 성별 구분 | 없음 | 남자만·여자만 골라 뽑기 |
| 중복 방지 | 없음 | **이어하기**로 뽑은 사람 누적 제외 |
| 결석 처리 | 없음 | 눌러서 토글 |
| 결과 | 캔버스 안 작은 글씨 | 교실 뒤에서도 보이는 큰 화면 |
| 모둠·순서 | 직접 계산 | 결과를 모둠/순서표로 정리 |
| 외부 통신 | 광고·통계·스프라이트 서버 | 전부 제거 |

## 7가지 상황 모드

모드를 고르면 **코스·속도·뽑을 등수**가 한 번에 맞춰집니다.

| 모드 | 언제 쓰나 | 걸리는 시간 |
|---|---|---|
| ⚡ 빨리 한 명 | 발표자 지목. 수업 흐름 안 끊기게 | 약 8초 |
| 🥁 두근두근 한 명 | 상품·특별한 역할. 끝까지 조마조마하게 | 약 40초~1분 |
| 👯 짝 뽑기 (2명) | 둘씩 짝지을 때 | 약 15초 |
| 👥 여러 명 뽑기 | 모둠 대표, 도우미 등 원하는 인원 | 약 15~20초 |
| 🧹 마지막 한 명 | 당번·심부름. 꼴찌가 당첨 | 약 15초 |
| 📋 발표 순서 정하기 | 전원의 순서를 한 번에 | 약 20초 |
| 🧩 모둠 나누기 | 전원을 골인 순서대로 N모둠에 고르게 배분 | 약 20초 |

`👥 여러 명 뽑기`와 `🧩 모둠 나누기`는 아래에 숫자 칸이 나옵니다.

## 명단은 번호가 기본입니다

`명단 편집`에서 **학생 수만 입력**하면 `1번 ~ N번`이 만들어집니다.
실명을 아예 저장하지 않으므로

- 공용 교실 PC에 학생 정보가 남지 않고
- 화면을 다른 반이 보거나 사진이 찍혀도 문제가 없으며
- 이 앱을 인터넷에 공개해 두어도 상관없습니다

이름이 꼭 필요하면 `이름` 탭으로 바꿔 입력할 수 있습니다.
그 경우에도 이름은 **그 브라우저의 localStorage에만** 저장되고 서버로 나가지 않습니다.
엑셀에서 이름 열을 복사해 붙여넣어도 되고, `1. 김철수` 같은 앞 번호는 자동으로 지워집니다.

## 성별로 나눠 뽑기

명단 편집에서 성별을 정해두면, 뽑기 화면 위에 **`전체` / `남자` / `여자` 탭**이 생깁니다.
탭을 고르면 그 성별 안에서만 뽑습니다. 탭마다 지금 뽑을 수 있는 인원이 같이 표시됩니다.

성별을 정하는 방법은 두 가지입니다.

- **한 번에**: `앞에서부터 N명이 남학생` → `한 번에 정하기`.
  번호가 남자 먼저 붙는 학급이면 이걸로 끝납니다
- **하나씩**: 번호(또는 이름)를 눌러 `남 → 여 → 미지정` 순환

성별을 하나도 정하지 않으면 탭은 나오지 않고 전체에서만 뽑습니다. 안 써도 되는 기능입니다.

## 이어하기 — 뽑은 사람 누적해서 기억

한 판이 끝나면 결과 화면에 세 가지 버튼이 나옵니다.

| 버튼 | 하는 일 |
|---|---|
| **한 번 더** | 같은 설정으로 바로 한 판 더. 방금 뽑힌 사람은 빠집니다 |
| **이어하기** | 설정 화면으로 돌아가되 **뽑힌 사람은 계속 제외**. 성별·모드를 바꿔 다음 판 |
| **새로 뽑기** | 누적 기록을 지우고 **전원 참가**로 되돌림 |

누적은 성별을 넘나들어도 유지됩니다. 예를 들어

1. `남자` 2명 뽑기 → 1번·2번 당첨 → **이어하기**
2. `여자` 2명 뽑기 → 13번·14번 당첨 → **이어하기**
3. 다시 `남자` 2명 뽑기 → **1번·2번은 자동으로 빠지고** 남은 10명 중에서 뽑습니다

설정 화면 위쪽에 `이어하기 중 · 이미 뽑힌 4명 제외`처럼 지금 몇 명이 빠져 있는지 항상 보이고,
`기록 초기화`로 언제든 되돌릴 수 있습니다. 날짜가 바뀌면 자동으로 초기화됩니다.

`📋 발표 순서`와 `🧩 모둠 나누기`는 전원이 대상이라 누적에 남지 않습니다.

## 교실에서 쓰는 흐름

1. **처음 한 번만**: `명단 편집` → 반 이름 + 학생 수 (+ 필요하면 성별) → 저장
2. **아침에 한 번**: 결석한 번호를 눌러 회색 처리
3. **수업 중**: 모드 고르고 `시작!` (또는 **스페이스바**)
4. 결과 화면에서 `한 번 더` / `이어하기` / `새로 뽑기`

## 저장되는 곳

반 명단·결석·뽑힘 기록·최근 결과는 전부 **그 브라우저의 localStorage**에만 저장됩니다.
서버도 없고 계정도 없습니다. 대신 브라우저 데이터를 지우면 명단도 함께 사라집니다
(번호 명단이면 학생 수만 다시 넣으면 되니 금방 복구됩니다).

## 실행

```bash
npm install
npm run dev
```

http://localhost:1235 에서 열립니다.

## 배포

`main`에 push하면 GitHub Actions가 빌드해서 GitHub Pages에 올립니다
(`.github/workflows/deploy.yml`).

저장소 설정에서 **Settings → Pages → Source를 `GitHub Actions`**로 한 번 지정해야 합니다.

USB나 교실 PC에 직접 두고 싶다면 빌드한 `dist/` 폴더를 통째로 복사하면 됩니다.
경로가 상대 경로라 어느 폴더에 두든 `index.html`을 열면 동작합니다.

```bash
npm run build
```
